## SECTION 2 — BACKEND PURPOSE & OBJECTIVES

1. **Heterogeneous Data Ingestion:** Provide REST endpoints and background job processing to ingest `.pdf`, `.docx`, `.xlsx`, and `.csv` files up to 100MB per file.
2. **Document Parsing & OCR Subsystem:** Integrate PyMuPDF text parser and Tesseract OCR 5.0 (300 DPI) to extract text, tables, layout metadata, and bounding coordinates.
3. **Structured Metric Store:** Parse and persist domain metric tuples `(mine_name, subsidiary, metric_name, numeric_value, raw_unit, standard_value, standard_unit, fiscal_year)` in PostgreSQL.
4. **Deterministic Validation Engine:** Convert legacy units to standard **MT** and execute arithmetic checks ($\sum \text{Mines} = \text{Subsidiary Total}$).
5. **Cross-Document Conflict Detection:** Identify duplicate metric entries for identical `(Mine, Metric, Year)` triplets and create `data_conflicts` records when values differ by $>1\%$.
6. **Vector & Metadata Indexing:** Generate 384-d embeddings using `SentenceTransformers (all-MiniLM-L6-v2)` and index 500-token chunks into ChromaDB.
7. **Hybrid Search Retrieval:** Execute parallel ChromaDB cosine vector search and PostgreSQL BM25 text search fused via Reciprocal Rank Fusion (RRF).
8. **Evidence Citation Gate:** Enforce mandatory page/table citation verification `[Doc_Name.pdf, Page X]` on all LLM-generated responses.
9. **4-Level Dashboard REST APIs:** Provide structured JSON aggregate data for Executive KPIs, Analytics Charts, Topic Intelligence, and Validation Alerts.
10. **Report Assembly & Export:** Assemble draft institutional reports and export formatted PDF documents via ReportLab.
11. **RBAC & Immutable Audit:** Enforce server-side JWT authentication, Role-Based Access Control, and append-only audit logging.

## SECTION 4 — CORE BACKEND PHILOSOPHY

$$\text{EVIDENCE} \longrightarrow \text{VALIDATION} \longrightarrow \text{INTELLIGENCE} \longrightarrow \text{REPORT}$$

* **Rule 1: Evidence-First:** Every query answer and report draft generated by the backend must carry explicit lineage metadata linking back to its original document, page, table, and chunk coordinates.
* **Rule 2: Deterministic Data Trust:** Numerical calculations, unit conversions, and arithmetic total checks are performed strictly via Python/SQL deterministic code—never by LLM inference.
* **Rule 3: Human-in-the-Loop Governance:** The backend creates explicit `data_conflicts` records for discrepancies, requiring reviewer intervention rather than silently overwriting data.

```python
# app/core/security.py - Password Hashing & JWT Implementation
from datetime import datetime, timedelta
from jose import jwt
from passlib.context import CryptContext
from app.core.config import settings

pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")

def verify_password(plain_password: str, hashed_password: str) -> bool:
    return pwd_context.verify(plain_password, hashed_password)

def get_password_hash(password: str) -> str:
    return pwd_context.hash(password)

def create_access_token(data: dict, expires_delta: timedelta = None) -> str:
    to_encode = data.copy()
    expire = datetime.utcnow() + (expires_delta or timedelta(minutes=settings.ACCESS_TOKEN_EXPIRE_MINUTES))
    to_encode.update({"exp": expire})
    return jwt.encode(to_encode, settings.SECRET_KEY, algorithm=settings.ALGORITHM)
```

## SECTION 12 — AUTHORIZATION & SECURITY MIDDLEWARE

```python
# Auth Dependency for Protecting Endpoints
from fastapi import Depends, HTTPException, status
from fastapi.security import OAuth2PasswordBearer
from jose import JWTError, jwt
from app.core.config import settings

oauth2_scheme = OAuth2PasswordBearer(tokenUrl="/api/v1/auth/login")

def get_current_user(token: str = Depends(oauth2_scheme)):
    credentials_exception = HTTPException(
        status_code=status.HTTP_401_UNAUTHORIZED,
        detail="Could not validate credentials",
        headers={"WWW-Authenticate": "Bearer"},
    )
    try:
        payload = jwt.decode(token, settings.SECRET_KEY, algorithms=[settings.ALGORITHM])
        username: str = payload.get("sub")
        role: str = payload.get("role")
        if username is None or role is None:
            raise credentials_exception
        return {"username": username, "role": role}
    except JWTError:
        raise credentials_exception
```

## SECTION 17 — DOCUMENT INGESTION PIPELINE SPECIFICATION

```
 [ UPLOAD PDF ] ──► [ HASH CHECK ] ──► [ PARSE TEXT/TABLES ] ──► [ OCR SCANS ]
                                                                      │
 [ INDEX CHROMADB ] ◄── [ CHUNK & EMBED ] ◄── [ VALIDATE METRICS ] ◄──┘
```

1. Client posts file to `POST /api/v1/documents/upload`.
2. Compute SHA-256 hash. If duplicate, return HTTP 409 (`DUPLICATE_DOCUMENT`).
3. Save raw file to `/storage/uploads/{hash}_{filename}`.
4. Insert `documents` record with status `PROCESSING`.
5. Trigger async task `process_document_background(doc_id)`.
6. Client receives HTTP 202 Accepted with document metadata.

## SECTION 18 — FILE VALIDATION ENGINE

```python
import hashlib

def validate_and_hash_file(file_bytes: bytes, filename: str) -> str:
    # 1. Extension check
    allowed_exts = [".pdf", ".docx", ".xlsx", ".csv", ".png", ".jpg"]
    if not any(filename.lower().endswith(ext) for ext in allowed_exts):
        raise ValueError("UNSUPPORTED_FILE_TYPE")
        
    # 2. Size check (100MB)
    if len(file_bytes) > 100 * 1024 * 1024:
        raise ValueError("FILE_SIZE_EXCEEDED")
        
    # 3. SHA-256 Hash
    return hashlib.sha256(file_bytes).hexdigest()
```

```python
# app/services/parsing_service.py - PyMuPDF Extraction Routine
import fitz # PyMuPDF
import pytesseract
from PIL import Image
import io

def parse_pdf_file(file_path: str):
    doc = fitz.open(file_path)
    pages = []
    for page_idx in range(len(doc)):
        page = doc[page_idx]
        text = page.get_text("text")
        # Check text density - if under 50 chars, trigger Tesseract OCR
        if len(text.strip()) < 50:
            pix = page.get_pixmap(dpi=300)
            img = Image.open(io.BytesIO(pix.tobytes("png")))
            text = pytesseract.image_to_string(img, config="--psm 6")
        pages.append({"page_number": page_idx + 1, "text": text})
    return pages
```

## SECTION 25 — NUMERIC NORMALIZATION ENGINE

```python
# Deterministic Unit Normalization Function
def normalize_to_mt(value: float, unit: str) -> float:
    unit_lower = unit.lower().strip()
    if "lakh" in unit_lower:
        return round(value * 0.1, 2)
    elif "million" in unit_lower or "mt" in unit_lower:
        return round(value * 1.0, 2)
    elif "thousand" in unit_lower:
        return round(value * 0.001, 2)
    elif "ton" in unit_lower:
        return round(value * 0.000001, 2)
    return round(value, 2) # Default assumption
```

```python
# Discrepancy Lookup Algorithm
def check_cross_document_conflicts(db, new_metric: MetricTuple, doc_id: int):
    # Query existing metrics for identical (mine, metric, fiscal_year)
    existing = db.query(ExtractedMetric).filter(
        ExtractedMetric.mine_name == new_metric.mine_name,
        ExtractedMetric.metric_name == new_metric.metric_name,
        ExtractedMetric.fiscal_year == new_metric.fiscal_year,
        ExtractedMetric.document_id != doc_id
    ).first()
    
    if existing:
        std_new = normalize_to_mt(new_metric.raw_value, new_metric.raw_unit)
        # If discrepancy > 1%
        if abs(existing.standard_value - std_new) / max(existing.standard_value, std_new) > 0.01:
            # Create Data Conflict Record
            conflict = DataConflict(
                metric_name=new_metric.metric_name,
                mine_name=new_metric.mine_name,
                fiscal_year=new_metric.fiscal_year,
                doc_a_id=existing.document_id,
                doc_a_value=existing.standard_value,
                doc_b_id=doc_id,
                doc_b_value=std_new,
                status="OPEN"
            )
            db.add(conflict)
            db.commit()
            return "CONFLICT_DETECTED"
    return "VALIDATED"
```

## SECTION 32 — HYBRID SEARCH ENGINE (VECTOR + BM25)

```python
# Reciprocal Rank Fusion (RRF) Reranking Logic
def reciprocal_rank_fusion(vector_results: list, bm25_results: list, k: int = 60) -> list:
    scores = {}
    for rank, doc_id in enumerate(vector_results):
        scores[doc_id] = scores.get(doc_id, 0) + 1.0 / (k + rank + 1)
    for rank, doc_id in enumerate(bm25_results):
        scores[doc_id] = scores.get(doc_id, 0) + 1.0 / (k + rank + 1)
    sorted_docs = sorted(scores.items(), key=lambda x: x[1], reverse=True)
    return [doc_id for doc_id, score in sorted_docs[:5]]
```
